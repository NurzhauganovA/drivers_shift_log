# Клиент «Дневник смен»

Flutter-приложение для iOS, Android и Web. Запуск, архитектура и принятые решения описаны в [README в корне репозитория](../README.md).

```bash
flutter pub get
flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:8000   # с сервером
flutter run -d chrome                                                     # демо-режим
flutter test
```
